# Maintainer runbooks (historical)

These documents are the original OfficeFC deployment's own runbooks, written while the app
was a private, single-deployment project. They refer to that deployment's Firebase project,
domain, accounts, and release process, and they are kept as history and as worked examples.

They are **not** instructions for running your own league. Use the
[self-hosting guide](../self-hosting.md) for that.

| Document                                           | What it was for                                                       |
| -------------------------------------------------- | --------------------------------------------------------------------- |
| [implementation-plan.md](implementation-plan.md)   | Architecture overview and delivery status before launch               |
| [running-m1.md](running-m1.md)                     | Milestone 1 local runbook: auth and membership                        |
| [running-m2.md](running-m2.md)                     | Milestone 2 local runbook: the first complete competitive loop        |
| [running-m3.md](running-m3.md)                     | Milestone 3 local runbook: the read-heavy league experience           |
| [app-store-submission.md](app-store-submission.md) | Taking the iOS app from TestFlight to unlisted App Store distribution |

Commands, paths, and settings in these files may be out of date. Where they disagree with
the [self-hosting guide](../self-hosting.md) or the
[Firebase backend reference](../firebase-setup.md), those documents are current.
