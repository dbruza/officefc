# Design history

These are design specs (`specs/`) and implementation plans (`plans/`) written during
OfficeFC's development, kept as design history. They record why features such as the
team-strength ELO handicap, rating integrity, the activity feed, and logging work the way
they do, and the multi-league groundwork assessment describes what supporting several
leagues in one deployment would take. They describe the code at the time they were
written; the code and the current docs are the source of truth where they differ.
